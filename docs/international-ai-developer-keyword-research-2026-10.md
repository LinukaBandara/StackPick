## Country research protocol — April 1 to October 10, 2026

Run the same seed groups separately for each country: US, UK, Canada, Australia.

Seed list:
- AI coding tools; AI coding agents; Claude Code; Cursor; GitHub Copilot; OpenAI Codex
- AI workflow automation; n8n; Make automation; Zapier AI; AI agents; LLM orchestration; LangChain; OpenAI Agents SDK
- AI for React; AI for Next.js; TypeScript AI tools; GitHub Actions; AI code review; DevOps AI tools; CI/CD tools
- best AI tool for [task]; [tool] pricing; [tool] free plan; [tool] alternatives; [tool A] vs [tool B]

For each seed, record:
- Country and exact query/variant
- Monthly search estimates for April–October 2026 where available (keep month-by-month values; do not infer from a 12-month average)
- Last-3-month direction vs previous 3 months
- Google Trends interest and rising related queries (relative interest, not absolute volume)
- Advertiser competition and top-of-page bid range, where available (not an AdSense revenue forecast)
- Current top-ranking page types and realistic ranking difficulty
- Whether StackPick already has a matching URL
- Proposed page type, unique evidence/test needed, and priority

Free/first-party starting points:
- Google Trends: https://trends.google.com/trends/
- Google Trends help on normalized data: https://support.google.com/trends/answer/4365533
- Google Ads Keyword Planner: https://ads.google.com/home/tools/keyword-planner/
- Keyword Planner historical metrics/location guidance: https://support.google.com/google-ads/answer/6325025
- Search Console: https://search.google.com/search-console/

Important data-quality rule: no exact monthly search-volume or CPC claim is accepted into the final priority list until its source, country, date range, and retrieval date are recorded. Third-party snapshots are supporting evidence only. Trends is normalized, Keyword Planner values are estimates, and CPC is not publisher RPM.

## Scoring and publishing rule

Score each validated keyword/page opportunity on a 1–5 scale:
- Demand in target countries
- Three-month growth / trend stability
- Search intent fit for a software discovery site
- Commercial relevance
- Realistic ranking opportunity
- Ability to add original hands-on value
- Fit with existing URLs (a duplicate/cannibalization risk lowers the score)

Publish only after checking the current site for overlap and documenting the evidence that makes the page useful. Prefer a few genuinely useful pages over mass-producing thin pages. A single-tool search should get a single-tool page when that matches the SERP intent; comparison searches should get a comparison page; implementation searches should get a tested tutorial.

## Implementation order

1. Complete country-by-country keyword validation and preserve raw exports.
2. Map validated terms to existing routes; improve existing pages when intent overlaps.
3. Select a small first batch of new AI coding and automation pages based on evidence.
4. Create original hands-on testing notes, screenshots, code/workflow examples, limitations, and official source links.
5. Add contextual internal links from existing AI and developer-relevant pages; avoid sitewide links to every new page.
6. Publish on the research branch, run a production build and route/canonical/sitemap checks, and review manually before any merge or AdSense changes.
7. Use Search Console query/page/country data to refine priorities every 2–4 weeks.

## Success criteria

Success is not the number of URLs published. Track:
- Relevant non-branded impressions and clicks by country
- Search queries and landing pages in Search Console
- CTR and position trends by query cluster
- Engagement and useful onward navigation in GA4
- Valid ad revenue only after AdSense approval and actual ads serving

No guaranteed rankings, traffic, AdSense approval, or earnings.
